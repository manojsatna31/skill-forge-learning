1️⃣ Install Python (3.10 or later)

Python is the core of this training. We recommend the latest stable version (3.11 or 3.12).

🖥️ Windows
  1. Download the installer from python.org.
  2. Check “Add Python to PATH” during installation.
  3. Select “Install Now” (or customise installation).
  4. Verify installation:
python --version
pip --version

Expected: Python 3.12.x and pip 24.x

🍎 macOS
  1. Download from python.org (recommended).
  2. Alternatively, use brew install python.
  3. Verify:
python3 --version
pip3 --version

Note: macOS uses python3 and pip3 by default.

🐧 Linux (Ubuntu/Debian)
  1. Update and install:
sudo apt update
sudo apt install python3 python3-pip python3-venv -y
python3 --version
pip3 --version

Most distributions include Python 3.10+ by default.

2️⃣ Install VS Code (or your preferred editor)

Visual Studio Code is lightweight, free, and has excellent Python support.

📥 Download & Install
  1. Go to code.visualstudio.com.
  2. Download the installer for your OS.
  3. Run the installer (keep default settings).
  4. Launch VS Code.
🧩 Recommended Extensions

Install from Extensions panel (Ctrl+Shift+X):

  • Python (Microsoft) – linting, debugging, IntelliSense.
  • Pylance – fast language server.
  • Python Debugger – debug scripts.
  • Jupyter – optional for notebooks.
  • Prettier – optional formatter.
  • GitLens – optional Git integration.
# Quick Open (Ctrl+P) and paste:
ext install ms-python.python
ext install ms-python.vscode-pylance
💡 Pro Tip: After installing the Python extension, press Ctrl+Shift+P, type “Python: Select Interpreter” and choose your installed Python version.

3️⃣ SQLite3 (Built‑in, but verify)

SQLite comes with Python, but it’s useful to have the standalone CLI.

🐍 Verify Python's SQLite 
python -c "import sqlite3; print(sqlite3.sqlite_version)"

Expected: 3.40.1 or higher.

🖥️ Standalone CLI (Optional)
  • Windows: Download from sqlite.org and add to PATH.
  • macOS/Linux: brew install sqlite3 or sudo apt install sqlite3. 
sqlite3 --version

4️⃣ Git – Version Control

Git tracks changes and is essential for collaboration and open‑source work.

📥 Installation
  • Windows: git-scm.com
  • macOS: brew install git
  • Linux: sudo apt install git
git --version
⚙️ Initial Configuration 
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

Required before your first commit.

5️⃣ uv – Fast Package Manager (Optional)

uv is the fastest Python package manager – works alongside pip.

# Install uv (macOS/Linux)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Or via pip (slower but works everywhere)
pip install uv

# Verify
uv --version

If you prefer pip + venv, that’s perfectly fine – uv is optional.

⚠️ Troubleshooting – Common Issues

  • “python is not recognized” (Windows): You missed “Add Python to PATH”. Re‑run the installer and select that option.
  • “pip is not installed”: Run python -m ensurepip.
  • “command not found: code” (macOS/Linux): Open VS Code, press Cmd+Shift+P (macOS) / Ctrl+Shift+P (Linux), type “Shell Command: Install 'code' command in PATH”.
  • “sqlite3” module not found: Extremely rare – reinstall Python.
  • Permission errors: Use python -m pip install --user package_name or use a virtual environment.
